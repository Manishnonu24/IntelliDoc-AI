# IntelliDoc AI

A production-ready AI agent system with RAG capabilities, featuring a FastAPI backend and a React frontend.

## Features
- **AI Agent**: Intelligent conversation with memory and tool use.
- **RAG**: Upload and chat with your documents.
- **Streaming**: Real-time token streaming for a responsive UI.
- **Modern UI**: Built with React, Tailwind CSS, and dark mode.

## Quick Start (Docker)

1. Set your OpenAI API Key in `.env`.
2. Run:
   ```bash
   docker-compose up --build
   ```
3. Open `http://localhost:3000`.

See [Walkthrough](walkthrough.md) for detailed instructions.
